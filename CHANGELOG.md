# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-22

### Added
- Initial release of Beacon Navigation package
- BLE beacon scanning and detection
- Indoor positioning using RSSI signal strength
- Dijkstra-based pathfinding algorithm
- Support for one-way and two-way corridors
- Connection types: normal, emergency, staff, stairs, elevator
- Visual map editor for configuration
- Beacon management UI
- Route builder with direction constraints
- Multi-floor navigation support
- Configuration storage with SharedPreferences
- Indoor map view widget
- Navigation state management with Cubit/BLoC
